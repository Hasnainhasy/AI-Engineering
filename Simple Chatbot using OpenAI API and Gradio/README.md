# 🤖 Simple AI Chatbot with OpenAI API

A simple AI chatbot built using the OpenAI API, OpenAI Python Client Library, and Gradio.

This project was created as part of my learning journey into AI Engineering and helped me understand how to connect an LLM API with a simple user interface.

## 📌 What I Learned

- How to work with the OpenAI API
- Using the OpenAI Python Client Library
- How system prompts work
- Giving the chatbot a specific role and context
- Sending user messages to an LLM
- Handling model responses
- Building a simple chatbot
- Creating a basic frontend using Gradio

## 🛠️ Technologies Used

- Python
- OpenAI API
- OpenAI Python Client Library
- Gradio

## ⚙️ How It Works

The application takes a user's message and sends it to the OpenAI model along with a system prompt.

The system prompt provides the model with information about its role and how it should respond.

The model then generates a response, which is displayed through the Gradio chat interface.

## 🖥️ Features

- Simple chat interface
- OpenAI API integration
- Custom system prompt
- Real-time AI responses
- Gradio frontend
